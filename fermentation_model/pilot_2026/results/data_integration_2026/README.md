# Pilot 2026 data integration results

This directory is regenerated by `python fermentation_model/pilot_2026/run_data_integration.py`.

The sampling window is defined by the first and last primary-result sample. MassView values are retained in Ln/min and are not normalized a second time. Raw 2.621 values are removed before same-second averaging. Leading/trailing zeros are retained, intermediate zeros are invalid, and edge fills are explicit artificial zeros. Controller mode 2 with a 9-11 °C band marks postprocess cooling; its event second is excluded from dynamic calibration. GC report values are diluted-vial concentrations and numeric values are multiplied by 1000 to recover MIX concentration. Lot 1 condensates are outside GC model scope.

The dataset remains conditional for calibration until the independent Ultra audit and confirmation of the MassView factory normal reference.
