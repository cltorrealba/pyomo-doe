# Shared model layer

The four campaigns use one shared model and data-processing layer. Campaign
folders must not contain copied versions of these modules.

## Active shared modules

- `../new_must_data_loader.py`
- `../run_new_must_glycerol_estimability_doe.py`
- `../run_secondary_metabolite_data_review.py`
- `../run_secondary_joint_campaign_doe.py`
- `../run_secondary_v2_model_evaluation.py`
- `../aroma_partition_unifac.py`

The modules remain in the `fermentation_model/` root for compatibility with the
existing imports. New notebooks generated by these modules belong in
`notebooks/`, not in the root.

The scientifically preferred estimation family is local IPOPT calibration
followed by estimability diagnostics, FIM/eigen-analysis and profile likelihood.
PSO and broad multistart artifacts are retained only as historical/transient
development evidence.
