# Administrative/evidence bundles

The `A07` and `A15` packages were assembled for rendition or evidence handoff.
They are preserved for traceability but are excluded from the current
scientific pipeline.

Do not select a model, parameter vector or experiment design solely because it
appears in one of these bundles. Current pilot results are documented in
`../README.md` and `../results/co2_solubility_integrated_doe/`.
