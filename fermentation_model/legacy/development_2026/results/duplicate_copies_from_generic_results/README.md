# Copias duplicadas de resultados iniciales

Esta carpeta conserva, por la politica de no eliminacion del repositorio, 23
archivos CSV que permanecian en la antigua ruta generica
`fermentation_model/results/` despues del reordenamiento.

Cada archivo es identico, byte a byte, a su homonimo en
`../initial_calibration/`. No constituyen una ejecucion adicional ni deben
usarse como fuente cientifica independiente.

La copia canonica para consulta historica es la ubicada en
`../initial_calibration/`.
