# Laboratory 2026 results

This directory owns all processed data, design outputs and scientific handoffs
specific to the Laboratory 2026 campaign.

Key families:

- `design_execution_bundle_2026-06-09/`: authoritative frozen design handoff.
- `final_operational_doe_volume_constrained/`: selected operational design.
- `lot1_data_preview/`: processed Lot 1 measurements and manual-entry templates.
- `estimability_old_vs_lot1/`: local calibration, FIM/eigen and profile comparison.
- `lot1_*`: sequential reassessment, timing and sampling design.

Raw sensor and analytical exports remain under `../../data/Laboratorio 2026/`.
